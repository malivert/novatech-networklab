# Contribuer

Merci de contribuer à NovaTech NetworkLab.

1. Créer une branche courte depuis `main`.
2. Ajouter ou modifier un scénario dans `data/scenarios.ts`.
3. Conserver une cause unique, trois indices progressifs et une correction vérifiable.
4. Ajouter les cas de test correspondants.
5. Exécuter `npm run lint`, `npm run typecheck`, `npm test` et `npm run build`.
6. Ouvrir une Pull Request en expliquant le symptôme, la cause et la validation.

Les contributions ne doivent introduire ni secret, ni compte obligatoire, ni dépendance à un service distant.
